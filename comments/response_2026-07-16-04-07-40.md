## Detail

### `skip_slow()` gate

`skip_if(!nzchar(...))` treated every non-empty value as "run," so a conventional
`RPBNB_RUN_SLOW=0` would launch the multi-minute slow tier. It now runs only for
recognized truthy tokens:

```text
RPBNB_RUN_SLOW=""      -> SKIP
RPBNB_RUN_SLOW="0"     -> SKIP
RPBNB_RUN_SLOW="false" -> SKIP
RPBNB_RUN_SLOW="1"     -> RUN
RPBNB_RUN_SLOW="yes"   -> RUN
RPBNB_RUN_SLOW="TRUE"  -> RUN
```

### Fixture count

`test-predict-unit.R` has **18** passing expectations, not 16. The prior
response's fixture-file comment is corrected. The fast-tier total (417) and the
combined 483 were already correct and are unchanged.

### Reproducible tier runner and CI

The verification command referenced `full_check.R`, which was a scratch script
never tracked in the repo. Replaced with `tools/test-tiers.R`, a tracked runner:

```text
Rscript tools/test-tiers.R fast          # nominal fast tier (slow gates skipped)
Rscript tools/test-tiers.R slow-predict  # RP prediction end-to-end fits
Rscript tools/test-tiers.R slow-copula   # test-rpbnb-copula.R
Rscript tools/test-tiers.R all           # all tiers
```

It sets `NOT_CRAN=true`, manages `RPBNB_RUN_SLOW` per tier, prints per-tier
counts, and exits non-zero on any failure (CI-friendly). `.github/workflows/tests.yaml`
runs the fast tier on push/PR and both slow tiers on a weekly schedule and on
manual dispatch, so the tiers are protected against regression rather than
manual-only. `tools/` and `.github/` are excluded from the source tarball via
`.Rbuildignore`.
