## Finding

### P2 - The covariance sensitivity experiment does not isolate the covariance wiring

**Locations:** `tests/testthat/test-fit-rpbnb.R:287-306`, `tests/testthat/test-cpp-likelihood.R:150-194`; compare `R/fit_rpbnb.R:448-512` and the “Proof that the new tests discriminate” section of the response.

The three-method test asserts, for each method, that `fit$bounds` differs from `fit$bounds_at_optimum`, that every non-NA SE is finite, and that `summary()` returns a coefficient table. None of those assertions says which interval produced the covariance. The mutation described in the response reinstated several old behaviors together, including setting `fit$bounds` to the optimum interval. That makes the first assertion fail once per method and explains the three reported failures without exercising the OPG, analytic-Hessian, or numeric-Hessian correction at all.

If only one covariance call site is reverted while the output fields remain correct, the current tests do not detect it:

- Dropping `lam_bounds = lam_frozen` from the `bnbr_rp_scores_cpp()` call in `fit_rpbnb()` leaves the direct wrapper test green because that test supplies the argument itself.
- Passing `lamLo_h`/`lamHi_h` to either Hessian path leaves the bounds premise and `summary()` shape unchanged.
- `all(is.finite(fit$se[!is.na(fit$se)]))` is also true when every SE is `NA`, because `all(logical(0))` is `TRUE`; it does not establish the response's claim that the SEs are finite.

Mutation-test each covariance branch independently, leaving `fit$bounds` untouched. Better, compare each fit's covariance with an explicit oracle evaluated at `coef(fit)` on the stored optimization draws and `fit$bounds`: `crossprod()` of frozen-bound scores for OPG, `bnbr_rp_hessian()` for analytic, and the fixed-bound numeric objective for numeric. The fixture has no fixed parameters, so the test can require `all(is.finite(fit$se))` directly. This would fail specifically when a covariance path uses the interval at the optimum while continuing to pass when only unrelated reporting fields change.
