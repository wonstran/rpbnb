## Findings

### P0 - Laplace Famoye fits are validated against Halton draws that are not part of their likelihood

**Locations:** `R/fit_rpbnb_tmb.R:362-382`, `R/fit_rpbnb_tmb.R:396-399`, `R/fit_rpbnb_tmb.R:561-595`; compare `src/rpbnb_tmb.cpp:672-687` and `src/rpbnb_tmb.cpp:857-870`.

`.lambda_bounds_at()` always sets `Rloc` from `draws` and realizes the finite `Z1`/`Z2` Halton grid. That is appropriate for `method = "sml"`, but `method = "laplace"` does not evaluate that grid: the template instead integrates per-observation Gaussian latent variables `u1`/`u2`. Consequently, `lambda_bounds_at_optimum` and `lambda_admissible` validate a different finite-draw model and can report `TRUE` while the Laplace integrand has a negative Famoye PMF in its latent tails.

A base-R reproduction with one Normal random coefficient in each margin, `beta = 0`, `sd = 0.2`, and `m = 0.5` gave bounds `[-2.550287, 3.131312]` from 5 Halton draws and `[-2.142173, 2.752759]` from 400 draws. For the corresponding independent Gaussian latent support, both conditional means can approach zero or infinity, so `c1` and `c2` can independently approach 0 or 1 and the full-support interval is `[-1, 1]`. A value such as `lambda = 2` can therefore be marked admissible by this check even though it is invalid for the Laplace model.

Make the validation estimator-specific. For Laplace, derive/enforce bounds over the latent support, or reject Famoye Laplace fits with random coefficients until the conditional PMF is guaranteed positive. At minimum, do not return `lambda_admissible = TRUE` from the Halton approximation on this path; return `NA` with an explicit warning.

### P1 - Non-Normal random-coefficient scales are still mislabeled as standard deviations

**Locations:** `R/tmb_methods.R:124-146`; distribution meanings are defined in `R/rand_dist.R:24-60`.

The revised table correctly removes the invalid Wald test and pairs natural estimates with delta-method natural-scale SEs. It still prints the heading `Random-coefficient SDs` and rewrites every `log_sd*`, `log_s*`, and `log_w*` row to `sd1:`/`sd2:`. For Uniform and triangular coefficients, `exp(log_w)` is a width parameter rather than the coefficient SD; for lognormal coefficients, `exp(log_s)` is the log-scale parameter rather than the natural coefficient SD. The output can therefore still be read as reporting a quantity it does not estimate.

Use a neutral heading such as `Random-coefficient scales` and preserve distribution-specific labels from `rand_dist_registry`. If actual coefficient SDs are desired, transform them separately with the distribution-specific formula and delta method.

### P2 - Timestamp disambiguation eventually falls back to overwriting the original file

**Locations:** `R/tmb_results_export.R:35-47`, with the write at `R/tmb_results_export.R:151`.

If the base timestamp and every suffix from `-2` through `-1000` already exist, the loop exits without changing `output_path`. `writeLines()` then overwrites the unsuffixed original without warning. A base-R reproduction precreating those paths returned the base path, emitted zero warnings, and replaced its sentinel content.

Stop explicitly when a bounded search is exhausted, or continue until a free name is found. If concurrent writers are in scope, reserve the path atomically rather than relying only on `file.exists()`.
