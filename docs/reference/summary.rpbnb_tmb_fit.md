# Summarize a fitted TMB-engine rpbnb model

Summarize a fitted TMB-engine rpbnb model

## Usage

``` r
# S3 method for class 'rpbnb_tmb_fit'
summary(object, digits = 4L, ...)
```

## Arguments

- object:

  A fitted model object of class rpbnb_tmb_fit.

- digits:

  Number of decimal places for numeric columns in coefficient tables.
  Default 4. Use a negative value (e.g. -1) for full precision.

- ...:

  Not used.

## Value

The fitted object, invisibly.
