Package Overview

rpbnb provides estimation and simulation of random-parameter bivariate negative binomial (RP-BNB) regression models. The package supports:

  • Fixed-parameter bivariate NB (Famoye/Sarmanov copula) with dependence
  • Random-parameter extensions with per-coefficient distribution choice
  • Per-coefficient specification of normal, lognormal, uniform, and triangular distributions
  • Efficient likelihood evaluation and analytic gradient computation
  • Simulation tools for model development and Monte Carlo experiments

Quick Start Examples

Simulating Data

library(rpbnb)

# Simulate from a random-parameter BNB model
sim <- simulate_rpbnb(
  n = 500,
  beta1 = c("(Intercept)" = 0.2, x1 = 0.4),
  beta2 = c("(Intercept)" = 0.1, x1 = -0.3),
  random_1 = list(x1 = list(sd = 0.5)),
  random_2 = list(x1 = list(sd = 0.4)),
  dispersion = c(m1 = 0.4, m2 = 0.5),
  seed = 123
)
head(sim$data)
sim$true  # True parameters

Fitting Models

# Fit a random-parameter model with per-coefficient distributions
fit <- fit_rpbnb(
  y1 ~ x1 + x2,
  y2 ~ x1 + x2,
  data = sim$data,
  random_1 = list(x1 = list(dist = "normal", scale = 0.3)),
  random_2 = list(x1 = list(dist = "lognormal", scale = 0.2))
)
summary(fit)

# Predictions on new data
newdata <- data.frame(x1 = c(0, 1), x2 = c(0.5, 0.5))
predict(fit, newdata)

Model Diagnostics

# Goodness-of-fit
bnb_gof(fit)

# Marginal effects at sample mean
bnb_marginal_effects(fit)

# Elasticities
bnb_elasticities(fit)

Technical Details

Random Coefficient Distributions

For random-parameter specifications, each coefficient can be assigned a distribution:

DistributionParameterizationUse Case
normalβ = μ + σ · z, z ~ N(0,1)Unbounded heterogeneity (default)
lognormalβ = ±exp(μ + σ · z), z ~ N(0,1)Strictly positive/negative coefficients
uniformβ = μ + σ · (2u - 1), u ~ U(0,1)Bounded support [-σ, σ]
triangularSymmetric triangular on [-σ, σ]Peaked heterogeneity near the mean

Sarmanov Bivariate NB

The fixed-parameter Sarmanov structure induces dependence between y1 and y2 via: 

P(Y1=y1, Y2=y2) = p1(y1) · p2(y2) · [1 + λ·(e^{-y1} - c1)·(e^{-y2} - c2)]

where λ controls the dependence strength (positive = positive correlation, negative = negative correlation). The valid range of λ is determined by the marginal means and dispersions.

Quasi-Monte Carlo Estimation

The random-parameter likelihood is estimated using randomized Halton sequences for quasi-Monte Carlo integration of the random-coefficient distribution. This approach provides faster convergence than standard Monte Carlo while maintaining reproducibility through seed control.
